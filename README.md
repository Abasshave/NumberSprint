# NumberSprint (PWA)

Maths and English quizzes. Installable, works offline.

## Put it on GitHub Pages
1. Create a new **public** repository on github.com.
2. Upload **all** files from this folder (keep the `icons` folder) and commit.
3. Repo **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
4. After a minute, open `https://YOUR-NAME.github.io/REPO-NAME/` (must be https).

## Updating later
Edit your files, then change `VERSION` in `sw.js` (for example `"1.0.0"` to `"1.0.1"`) so phones drop the old offline copy.

## Install
- Android / desktop Chrome or Edge: tap **Install app** (or browser menu, Install).
- iPhone / iPad: Safari, **Share, Add to Home Screen**.

Scores are saved per device and browser.
